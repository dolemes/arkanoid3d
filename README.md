# ARKANOID 3D — Cyber-Minimalist

Brick breaker 3D em estilo cyber-minimalista (neon, grid, bloom), feito com Three.js e WebAudio.
Arquivo único, sem build.

## Jogar online
https://www.dolemes.com/games/arkanoid3d/

## Controles
- Mouse / A-D / setas: mover o paddle
- Clique / Espaço: lançar a bola e atirar (laser)
- P: pausa • M: som

## Recursos
- 5 dificuldades, 10 fases com mecânicas próprias
- Power-ups: Laser, Expansor, Multibola, Ímã, Escudo (e negativos nos níveis 4–5)
- Ranking local (localStorage)
- Debug: `?level=7&diff=3&name=Neo`
